# eRecht24 Bundle – Dokumentation

Symfony-Bundle für automatischen Push & Pull von eRecht24-Rechtstexten
(Impressum und Datenschutzerklärung, jeweils Deutsch und Englisch).
Betriebsarten: **Single** (API-Key in `.env.local`) und **Multi-Tenant**
(API-Keys in der Datenbank der Anwendung).

3. [Umsetzungsplan](03-umsetzungsplan.md) – Phasen, Tests, offene Fragen
